How It Works

This dashboard tracks Arif's easy aerobic runs from the COROS Training Hub, logged daily into a Google Sheet. Each morning an automated task reads yesterday's activity, updates the sheet, and redeploys this page to Netlify. Easy runs are identified by Menu labels containing "easy" or "over the hills" (case-insensitive). Week labels: Pre = before 26-Mar-26, Wk 1 = 26-Mar to 1-Apr, then 7-day blocks onward. The chart shows HR as a solid area (cyan) and pace as a dashed line (purple), with week dividers and a linear regression trend for HR. 🏅 PB = personal best (fastest pace or lowest HR across all runs). Click any table row or chart point to highlight it.
